## Visualization Assets

The 3D assets under `examples/viz/web_viz/static/assets/` are visualization
assets. They are not relicensed by the repository-level Apache-2.0 license.
For Sketchfab assets, the active runtime visual is kept as a GLB.

The downloaded source packages were retired from the working tree on
2026-08-13 because nothing loads them at runtime and Git history preserves
them. `examples/viz/web_viz/static/assets/audit_ledger.md` records each
retired file with its size, SHA-256 digest, and a `git show` recovery command.
The digests quoted below stay valid as provenance for the shipped GLBs. One
package is exempt: the extracted F-16 glTF under
`assets/air/audit/f16_c_falcon_carlos_maciel/gltf/` remains on disk because
`tools/geometry/airframe_review` parses it as a live geometry-review input.

### Retired F-16 FlightGear candidate

The previous root-level F-16 visualization asset was archived under
`examples/viz/web_viz/static/assets/archive/f16_flightgear_gplv2_candidate_20260611/`
and retired from the working tree on 2026-08-13. It was never the active
visualization asset. The provenance review identifies it as a strong candidate
derivative of the FlightGear `NikolaiVChr/f16` GPLv2 aircraft package, so it
must not be treated as repository-level Apache-2.0 content and no mainline
geometry may be derived from it. The review conclusion, the `f16.glb` SHA-256
`7c432edcaec14bc52a262d2ef311b19c525452e2614400c3c10f8e93da1b7ee0`, and the
Git recovery command are preserved in
`examples/viz/web_viz/static/assets/audit_ledger.md`.
