# Naval Tasking Skeleton

This directory hosts the first-stage `naval` tasking skeleton for the
`common + air + naval` split.

Scope for WP7:

- keep joint/common fields in `common/*`
- keep existing air sortie semantics in `air/*`
- reserve naval-specific organization and station semantics here

This directory does not introduce a full naval runtime. It only provides
stable landing points for future naval tasking DTO growth.
