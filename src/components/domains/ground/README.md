# `src/components/domains/ground` Boundary

This directory is the component-layer owner for accepted ground-domain owner
slices. It currently covers combat placeholders plus the G0/G1 static
command/tasking surface; it is not a release of full ground movement, sensing,
fires, terrain, or runtime ownership.
