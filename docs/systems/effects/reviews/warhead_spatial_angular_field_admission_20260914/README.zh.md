# 弹头空间角向场准入评审

状态：破片角向场准入通过；总体弹头空间场准入仍保持 hold。

本评审在保留的 384 行空间矩阵上加入模型拥有的极向/方位向破片密度，以及可开关的近场地板。探针继续绕过制导和引信决策，使用维护中的 F-16C 命中盒包络与合成弹头剖面。

## 证据边界

- 数据库只读加载；探针没有修改默认武器或飞机参数。
- 角向剖面是合成参数：`polar_azimuthal`、浓度 `0.5`、各向同性比例 `0.55`、两个方位瓣、`0.10` 调制。这些值用于证明字段路径，不是实装武器标定数据。
- 制导、跟踪、引信决策仍被绕过；本批次不声明综合命中概率或杀伤率。
- 连续杆仍是旧的侧扫替代模型，本批次只做回归核验，不对其调参。

## 模型拥有的角向场

对破片行，模型现在导出有符号极向余弦、极向角、方位角、极向密度、方位密度和混合角向密度。混合密度会作用于破片空间图样；legacy 标量剖面继续保留原先的绝对点积行为。剖面参数和每个导出样本都进入事件 DTO 与 Python 绑定。

## 结果

完整矩阵共 384 行：两个族、六个方向、四个距离、八个起爆航向。

- 投影追踪：384/384 有效；后限幅、前限幅、候选聚合和标志闭合检查全部通过。
- 破片角向场：192/192 行激活；距离单调、左右镜像和轴向（front/back）方向符号残差均为 0。该族相邻 45° 最大变化为 `0.09224384286905474`。
- 报告保留破片族 10 个非轴向符号塌缩，全部位于 right/left/up/down 的赤道几何，此时径向样本相对于方向框架的极向余弦接近 0，因此极向分布在 0/180 比较中预期对称。它们被显式报告，没有被静默忽略。
- 连续杆回归：与 `warhead_spatial_structural_admission_baseline_20260913.json` 比较 192/192 行；空间、机制、命中估计和杆切割字段的差异数为 0。
- 近场地板消融：24 对样本；启用开关在 12 对实际生效，禁用开关在 0 对生效，12 对改变了效果尺度；最大成对差值为 `0.040703117619857065`。

## 准入结论

诊断追踪门和破片角向场准入通过。总体弹头空间场准入仍保持 hold，原因是连续杆尚未实现显式的扩张环带与目标几何相交。组件负载准入和综合杀伤链准入尚未评估。
