## 当前结论

最有用的第三方候选是 `AIM120-TPC-001` 和 `AIM120-TPC-002`，因为它们可追溯、字段较具体，并与 `AIM120-TPC-006` 对 C-class 40 lb / 18 kg 级说法形成弱交叉。最重要的拒绝项是 DCS / War Thunder / forum / tabletop game 参数，它们即使可访问，也只能防止误用，不能提供引信半径、杀伤半径、damage 或 Pk。

本轮没有新增任何可进入运行时的 AIM-120C warhead/fuze authority。所有新增材料只扩大候选池和 residual 可审计性。
