# A2 组件失效 / 脆弱性 benchmark 方法来源账本

状态：`2026-05-28` 公开候选与拒绝清单。所有记录默认 `non-authoritative`。本文件只记录公开方法来源和准入判断，不创建 vulnerability descriptor，不写真实校准 row，不授予 Pk、deterministic fuze、effect-scale 或 component-failure probability authority。

## 字段口径

| 字段 | 说明 |
|---|---|
| `source_ref` | 稳定 URL、DOI、报告号、标准号、法规入口或公开题录。 |
| 发布方 | 官方机构、标准机构、出版社、期刊或公开来源持有人。 |
| 可公开性 / 权利 | 公开访问、版权/再分发限制、是否只能引用不能复制正文。 |
| Tier | 按 A2 source admission rules：`Tier A / 官方-标准`、`Tier B / 公开工程材料`、`Tier C / sanity check`、`rejected`。 |
| scope 匹配 | 与 A2 component fragility / vulnerability benchmark 的匹配程度。 |
| 可支持 | 仅指文档态用途：`component_kill_criteria`、`failure_probability_surrogate_benchmark`、`redundancy_dependency_validation`、`residual_register`、`validation_criteria` 或 `sanity_check_only`。 |
| 交叉验证 | 与哪些公开来源或已有组件包互证。 |
| 不确定性 | 采纳后仍无法关闭的真实性缺口。 |
| admission / authority | 准入结论；所有候选均保持 non-authoritative。 |

## 按能力映射的准入判断

| 能力 / 字段 | 可作为公开候选的来源 | 当前允许动作 | 当前禁止动作 |
|---|---|---|---|
| `component kill criteria` | FOI-R--2829--SE、Ball、MIL-HDBK-336、Li 2013、shotline 2009、Lomazzi 2022 | 定义 failure-state taxonomy、component/system consequence、dependency graph 测试问题 | 写入真实 F-16C component Pcd|h、复制受版权表格、推断 weapon-specific kill thresholds |
| `failure probability surrogate benchmark` | NASA damaged-aircraft consequence、NASA-STD/HDBK-7009、fragment/structure impact open papers | 设计 non-authoritative benchmark、误差指标、coverage / uncertainty 记录 | 把 benchmark 输出当 `calibration_status=calibrated` 的 row |
| `redundancy/dependency validation` | FOI fault-tree、Li product structure、FAA AC 25.1309、FAA AC 20-128A、JASP public component focus articles | 验证 dependency propagation、redundancy isolation、failure condition severity 映射 | 把 civil probability classes 或 public workflow 变成 combat fragility probability |
| `residual register` | NAP、GAO、10 U.S.C. LFT&E、JASP/DOT&E public reports、NASA/FAA scope limitations | 记录 full-up evidence 缺口、试验数据缺口、scope mismatch | 用 residual discussion 替代真实 validation data |

## 尚未关闭的问题

- `CFBM-LFTE-003` 已固定到 10 U.S.C. § 4172 的公开镜像；后续仍应补官方 U.S. Code permalink / version date，避免法典页面参数漂移。
- NASA-STD-7009 / NASA-HDBK-7009A 需要固定具体版本、PDF URL、rights、sha256 和适用条款。
- MIL-HDBK-336 需要从 DLA ASSIST 固定公开版本、distribution statement、版本状态和 hash；未固定前只作候选。
- 公开论文的 open-access / Creative Commons 条款需在任何图表复用前逐篇核对；当前账本仅引用 DOI/题录和自写摘要。
- 仍未找到可公开、可再分发、scope 匹配且含 uncertainty 的 aircraft air-combat component fragility calibration dataset。
