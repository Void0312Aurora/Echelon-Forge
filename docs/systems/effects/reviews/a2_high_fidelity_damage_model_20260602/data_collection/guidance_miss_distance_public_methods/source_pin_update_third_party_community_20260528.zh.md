## 本轮结论

第三方/社区资料可用于三类窄用途：

| 用途 | 当前可接收内容 | 最高结论 | 不允许 |
|---|---|---|---|
| BVR 交战距离与 public AAM range 量级 | think-tank / professional media / hobbyist database 中可追溯的公开 range 说法、历史 BVR 趋势和 launch-condition caveat | `third_party_range_sanity`、`BVR_context_candidate` | 真实 NEZ、真实 envelope、具体型号 Pk、战术有效性真值 |
| PN / APN / 6DOF / seeker-filter 开源实现 | 有 repo、license、commit/tag 或论文入口的开源 scaffold | `open_source_reproducibility_candidate`、`benchmark_design_reference` | 真实 seeker、autopilot、propulsion、aero 或 AIM/R 系校准 |
| 游戏/商业仿真/社区配置 | DCS、War Thunder、CMO viewer 等用于识别单位、动态 range 依赖、社区争议和游戏平衡风险 | `community_sanity_check` 或 `rejected_as_truth` | 不能作为参数真值、fuze radius、lethal radius、Pk 或 runtime calibration |

## 使用规则

- Future benchmark manifests must cite `source_id`, not bare URLs.
- Public range entries from third-party sources must be stored as qualitative bins or contradiction notes unless launch condition axes are explicit.
- Open-source code may become a reproducibility scaffold only after exact commit/tag, license, dependency lock, run command, seed and output hash are recorded.
- Game and commercial simulation records remain rejected or `community_sanity_check_only`; they must never become source rows for A2 runtime descriptors.
- All rows here retain `authority=none`.
