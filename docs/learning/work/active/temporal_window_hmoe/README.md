## Objective

Determine whether a bounded observation-history window improves Stage-0 and
Stage-1 air-combat weapon-employment behavior enough to justify a heavier
sequence-native policy. Physical state remains in simulation contracts;
behavioral memory belongs to the policy.

## Current Status

The package remains an evidence-collection line. Runtime and extractor slices
entered validation and comparative reactive/temporal probes exist, but the
evidence does not authorize the M2 causal-Transformer implementation.
