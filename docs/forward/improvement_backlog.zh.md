# 改进积压工作（空战重点）

本文档列出了候选改进及其重要性。这是一份动态的积压工作清单，用于指导后续迭代。

## P0 - 正确性与一致性
- 飞行动力学：增加推力/阻力或比剩余功率（SEP）模型，使速度/高度/转弯性能权衡保持一致。
- 传感器输出：统一检测时间戳、字段和过滤规则，避免不一致的接触列表。
- 制导/控制耦合：确保动作限制（过载、失速）在控制和运动系统中得到一致遵守。
- 场景验证：在执行前根据模式验证 JSON 配置。

## P1 - 真实性与行为
- 大气模型：空气密度随高度变化，影响阻力和爬升。
- 导弹能量：燃尽、阻力和导引头限制（视场、锁定距离）。
- 雷达模型：探测概率、信噪比阈值和航迹记忆。
- 损伤模型：组件级损伤（发动机、雷达、操纵面）。

## P2 - 训练与分析
- 动作/观测归一化，每单位类型具有显式边界。
- 用于训练的奖励模板和事件钩子。
- 确定性重放，包含事件日志和元数据快照。
- 用于指标和回归测试的场景批量运行器。

## P2 - 工程加固
- 保持 `pyproject.toml` 依赖组与受维护的冒烟、强化学习、训练和世界模型入口点对齐；在宣称可重复训练运行之前，添加锁文件或环境文件。
- 将根级别的训练脚本压缩为 CLI/编排粘合剂。`train.py` 已使用 `python/training/`；`world_model_train.py` 应在添加更多世界模型功能之前进行等效的分阶段拆分。
- 将物理合理性检查升级为契约测试：起飞距离界限、爬升率和速度包线限制、燃油单调性、重量变化、风的影响以及自动驾驶路径中无能量凭空增加。
- 一旦构建、冒烟测试、最小训练冒烟、已知限制和工件输出策略都从全新环境中记录完毕，准备 `v0.1.0-alpha` 发布检查清单。

## P3 - 可扩展性
- 多保真度模型（低/中/高），可按场景选择。
- 包含版本化模式的单位和武器定义资产库。
- 用于传感器、制导和效果的插件式模型注册表。
