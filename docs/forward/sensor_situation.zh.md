# 传感器与态势感知计划

本文档记录了传感器真实感及由此生成的态势图（航迹、记忆、不确定性）的路线图。

## 当前已实现特性
- 扫描周期：`scan_period` 和 `last_scan_time` 控制扫描门控。
- 探测概率：`detection_prob` 配合距离衰减（`range_power`）。
- 测量噪声：`bearing_noise_std`（度）、`range_noise_std`（米）。
- 航迹记忆：`track_memory_s` 在扫描未命中时保留接触点。
- 目标方位影响：`aspect_influence` 根据目标航向缩放探测概率。

## 传感器参数（每单位）
- `max_range`：最大探测距离（米）。
- `fov_deg`：总视场（度，NAV）。
- `scan_period`：扫描间隔时间（秒）。
- `detection_prob`：基准探测概率 [0,1]。
- `range_power`：距离衰减指数。
- `bearing_noise_std`：方位噪声标准差（度）。
- `range_noise_std`：距离噪声标准差（米）。
- `track_memory_s`：接触点保留时间（秒）。
- `aspect_influence`：方位影响权重 [0,1]，用于方位相关探测。

## 探测模型（总结）
1) 距离和视场门控。
2) 概率 = detection_prob * range_factor * aspect_factor。
3) 若探测到：对方位/距离施加高斯噪声。
4) 与航迹记忆合并以避免硬性丢失。

## 态势图说明
- `ContactList` 当前仅存储点探测（无滤波器）。
- 航迹记忆提供短期持久性，但无完整跟踪滤波器。
- 噪声和丢包通过种子哈希实现每扫描确定性的处理。

## 计划扩展
- 航迹滤波器：alpha-beta 或卡尔曼滤波器，含每条航迹的协方差。
- 航迹 ID 与质量评分（置信度、年龄、最后更新时间）。
- 多传感器融合：按优先级规则组合雷达/光电航迹。
- 俯仰/方位噪声分离及 3D 视线角度。
- 干扰/电子对抗：根据目标状态降低探测概率。
- 导弹导引头限制（瞄准线角度、锁定时间）。

- 创建传感器回归测试，验证确定性和丢包行为。
