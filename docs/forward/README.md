# Forward Notes

This folder collects forward-looking plans and improvement ideas that are not
yet scheduled into implementation tasks, organized by topic.

## Directory

| Subdirectory | Content |
|-------------|---------|
| `air_combat/` | Air combat damage model evaluation and improvement backlog |
| `weapons/` | Weapons and engagement rules roadmaps, implementation notes, termination logic |
| `c2/` | C2 communication and command chain, operation layer and action space |
| `physics/` | Physics engine upgrade roadmap |
| `rl/` | Reinforcement learning and self-play roadmap |
| `sensor/` | Sensor and situational awareness plan |
| `viz/` | Visualization stack evolution toward operational/strategic scale |
| `models/` | Hierarchical MoE execution policy design freeze |
| `temp/` | Scratch-note index and authority boundary for retained temporary notes |

Release-specific checklists and reproducibility notes should live alongside
the concrete task or plan docs once a release is actually scheduled.
