yet scheduled into implementation tasks.

- operation_layer.md: action-space and operation-layer design notes.
- sensor_situation.md: sensor and situational awareness roadmap.
- weapons_engagement.md: weapons and engagement rules roadmap.
- weapons_engagement_impl.md: implementation notes for weapons/engagement rules.
- engagement_termination.md: termination rules and behavior logic roadmap.
- rl_selfplay.md: reinforcement learning self-play roadmap.
- c2_communication.md: command link and C2 constraints roadmap.
- models/hierarchical_moe_execution_policy.md: design freeze for the execution-layer hierarchical MoE line.
