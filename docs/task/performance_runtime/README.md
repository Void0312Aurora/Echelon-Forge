This subproject tracks the runtime-performance work that follows the temporary
freeze of the realism/fidelity deepening line. Its job is to define the
optimization ladder first, then keep the current compute-chain analysis and
benchmark-oriented optimization entrypoints in one place.

## Scope

1. Benchmark-aligned performance status after the realism freeze.
2. Optimization ordering, escalation rules, and acceptance boundaries.
3. Runtime/env/observation/reward hot-path analysis before code changes.

## Not Maintained Here

1. New realism-deepening work packages.
2. Scenario-design or reward-design changes whose primary goal is not runtime performance.
3. Approximate or semantics-changing optimization proposals before level-1 and
   level-2 evidence is exhausted.
