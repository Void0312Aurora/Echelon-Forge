## 一、当前系统管线概览

当前飞行动力学管线按 ECS 注册顺序构成：

```
AeroStateSystem       → 计算迎角/侧滑角/动压/马赫
ForceClearSystem      → 清零 ForceAccumulator
ForceSystem           → 添加重力 + 推力（含密度/马赫标定）
AerodynamicsSystem    → 添加升力 + 阻力 + 气动力矩
GroundContactSystem   → 地面弹簧-阻尼 + 轮胎摩擦 + NWS
RotationalIntegration → Euler 方程 + Euler 角运动学
LeapfrogIntegration   → Störmer-Verlet 平移积分
```

控制链路为：

```
PilotAction / MissionCommand
  → ControlModel (FBW 速率指令 / 自动驾驶)
    → ControlLawState
      → 控制力矩注入 ForceAccumulator
```

## 二、已知失真点

### 2.1 升力模型

| 失真 | 代码位置 | 真实情况 |
|------|----------|----------|
| **Cl_α 固定 0.1/deg，无马赫依赖** | `aerodynamics_system.h:64` `kClAlphaPerDeg = 0.1` | Prandtl-Glauert 压缩性修正：`Cl_α(M) = Cl_α(0) / √(1-M²)`（亚声速），超声速按 Ackeret 理论下降。跨声速区（M 0.8-1.2）Cl_α 峰值可达低速的 2-3 倍。当前模型在高亚声速严重低估可用升力，超声速高估 |
| **失速迎角硬编码为常量** | `aerodynamics_system.h:83` `alpha_stall_deg = 15.0 + 6.0*flaps` | 真实失速迎角随马赫数（压缩性降低失速迎角约 2-4°）、雷诺数、襟翼偏度非线性变化。当前襟翼效应仅有简单偏置 |
| **深失速平台 Cl=0.22 物理不合理** | `aerodynamics_system.h:88` `cl_deep_mag = 0.22` | 真实深度分离流区域升力系数剧烈振荡（非定常涡脱落），不存在平稳平台。90° 迎角时平板 Cl≈0（纯阻力），不应保持恒定 |
| **无负迎角失速不对称** | `aerodynamics_system.h:79` `alpha_abs` 判定 | 有弯度翼型的正/负失速行为不对称。负迎角失速通常更早（Cl_min 约 -0.8 到 -1.2），而正迎角失速 Cl_max ≈ 1.2-1.6 |
| **无侧滑-升力耦合** | 升力计算完全独立于 beta | 大侧滑角时有效后掠角改变，影响升力线斜率。典型战斗机在 β=20° 时 Cl_max 可下降 10-15% |

### 2.2 阻力模型

| 失真 | 代码位置 | 真实情况 |
|------|----------|----------|
| **Cd0 硬编码 0.02，无马赫依赖** | `aerodynamics_system.h:108` `double Cd0 = 0.02` | 跨声速波阻使 Cd0 在 M>0.8 急剧增加。M=1.0 附近可达亚声速的 3-5 倍，面积律设计可减轻但不可消除。当前模型在跨声速区严重低估阻力 |
| **k=0.1 常量，无马赫依赖** | `aerodynamics_system.h:124` `double k = 0.1` | 跨声速区激波/边界层干扰增大诱导阻力因子 |
| **诱导阻力地面效应修正精度不明** | `aerodynamics_system.h:142` `k_eff = k*(1 - 0.70*ge)` | 该公式适用于大展弦比机翼。低展弦比三角翼/切尖三角翼布局的地面效应削减幅度为 30-50% |
| **无外挂物干扰阻力** | `aerodynamics_system.h:110` 仅加 `0.001*drag_index` | 外挂物除自身阻力还需机身/机翼干扰阻力（占外挂总阻力 20-40%），当前完全缺失 |
| **无底阻/波阻/诱导阻力分解** | 单一 Cd0 + k*Cl² | 真实阻力应分解为型阻（摩擦+压差）、诱导阻力、波阻，各有不同的速度/迎角依赖 |

### 2.3 力矩模型

| 失真 | 代码位置 | 真实情况 |
|------|----------|----------|
| **无操纵面导数** | 力矩模型无 Cl_δa、Cm_δe、Cn_δr | 真实俯仰力矩 = Cm_α·α + Cm_δe·δe + Cm_q·q_hat + Cm_α̇·α̇_hat。控制面偏转产生的力矩与稳定性力矩同等重要。FBW 虽以力矩方式注入控制，但操纵面偏转同时改变裸机气动特性（如 δe 改变平尾有效迎角从而改变全机 Cm_α） |
| **缺少 Cm_α̇（下洗滞后阻尼）** | 无该项 | 迎角变化率引起的俯仰力矩（源于平尾处的下洗滞后）对短周期模态至关重要。缺少此项导致短周期阻尼偏低、频率偏高 |
| **无 Cn_p（滚转引起的偏航）** | `aerodynamics_system.h:245` 注释 `// Neglect Cn_p for now` | 滚转时左右翼不对称产生偏航力矩，是荷兰滚模态关键项 |
| **稳定性导数为硬编码常量** | `Cm_α = -0.8`, `Cn_β = 0.15` | 真实导数随 α、M 显著变化。高 α 时因下洗增强，平尾效率变化改变 Cm_α。跨声速激波位置移动大幅改变各导数 |
| **Cm_α 固定为稳定飞机** | `Cm_α = -0.8` | 现代战斗机（F-16、Su-27）采用放宽静稳定度（RSS），亚声速 Cm_α ≈ -0.2 甚至微正——完全依赖 FBW 增稳。当前模型将这一决定性设计特征抹平为传统稳定布局 |
| **深失速阻尼衰减统一** | `aerodynamics_system.h:223` `damp_scale = 1 - 0.7*stall_rel` | 失速时俯仰阻尼（平尾沉浸于分离尾流中）衰减最快，偏航阻尼（垂尾仍在相对干净气流）衰减最慢。不应统一用一个系数 |

### 2.4 失速/过失速动力学

真实物理与当前模型之间的系统性偏差：

```
真实物理                              当前模型
────────                              ────────
Cl 在失速迎角附近有尖锐弯折          smoothstep 平滑过渡
Cm 在失速时出现强烈低头力            Cm 线性延续至深失速，
矩（pitch break，压力中心后移）       俯仰力矩来自 Cm_α·α 的线性外推
横航向阻尼大幅下降，出现             阻尼统一缓慢衰减，
机翼摇晃（wing rock）                无 wing rock
失速-改出有显著迎角滞回（hysteresis） 无滞回效应
```

pitch break 的缺失尤其关键——真实飞机失速时压力中心后移，产生强低头力矩帮助
自动改出。当前即使在 >30° 迎角仍然使用 `Cm_α = -0.8` 的线性外推，
严重低估了大迎角的低头恢复趋势，同时抹平了 pitch break 作为失速"可感知
物理信号"的训练价值。

### 2.5 推力与推进系统

| 失真 | 代码位置 | 真实情况 |
|------|----------|----------|
| **油门准二值化** | `force_system.h:127-132` >0.9 直接跳全加力 | 真实涡扇发动机有连续推力曲线。加力段有独立调节（4-5 级），非 0/1 开关 |
| **无发动机瞬态延迟** | 推力指令瞬间生效 | 慢车→军推需 2-4 秒（转子惯性），军推→全加力需额外 1-2 秒（点火+火焰稳定）。缺少此延迟使 RL 学到高频油门脉冲——在真实发动机上因热循环/超温完全不可行 |
| **ram 因子无上界衰减** | `force_system.h:152` `1.0 + 0.3*M` | M>1.5 时进气激波损失抵消 ram 收益。M=2.0 时实际 ram 因子约 1.2-1.3 而非 1.6 |

| **无燃油-推力一致性** | `LogisticsSystem` 独立计算油耗 | 加力 SFC 为军推 2-3 倍，油耗应随推力一致变化 |

### 2.7 积分器精度

| 失真 | 代码位置 | 真实情况 |
|------|----------|----------|
| **Leapfrog 非真 Velocity-Verlet** | `leapfrog_system.h:67-79` | 两半 kick 均使用 a(t) 而非 a(t+dt)。对时变气动力，这是一阶近似而非严格保辛。真 Velocity-Verlet 需要 re-evaluate 力函数获取 a(t+dt) 做第二半 kick |

## 三、当前不应采用的表述

为避免后续语义漂移，当前以下表述应明确避免：

1. 不应将当前气动模型称为"真实飞行力学仿真"——它是
   **"教科书线性气动 + 简化失速 + 无压缩性效应"**。
2. 不应将当前 FBW 系统称为"F-16 级飞控"——它是
   **"通用速率指令 FBW 抽象"**，无 g-指令、无控制分配、无 RSS 增稳。
3. 不应将当前推进系统称为"涡扇发动机仿真"——它是
   **"双点推力 + 密度/ram 标定"**，无瞬态、无温度效应、无 RPM。
4. 不应将当前失速模型称为"过失速动力学"——它是
   **"静态升力系数 smoothstep 过渡"**，无 pitch break、无 wing rock、无滞回。

更准确的表述是：

- **RL 训练级一致物理环境**
- **简化线性气动 + 失速过渡 + FBW 抽象**
- **适用于起降/巡航/基本机动训练，不适用于跨声速/超声速/过失速对抗**

## 四、为什么飞行动力学是空战前置条件

空战模拟里，飞行动力学不是"背景层"，而是决定训练是否学歪的底座。

### 4.1 能量机动是空战核心变量

空战决策大量依赖以下量之间的真实耦合：

- 速度
- 高度
- 推力
- 阻力
- 法向过载
- 机头指向速率

如果这些量的相对关系失真，策略即使在当前环境里"赢"，学到的也可能只是
对简化模型的投机路径，而不是可迁移的战术。

### 4.2 飞控/气动失真会直接改变"可学动作空间"

对 RL 而言，动作空间不是 `stick_pitch / stick_roll / throttle` 的字面定义，
而是这些动作在世界里实际能换来什么姿态与能量变化。

一旦出现以下偏差，策略就会被系统性引向错误方向：

- 油门可以瞬时给出真实发动机不可能提供的推力变化
- 高攻角区没有真实的 pitch break / 恢复趋势
- 横滚、俯仰、侧滑响应过强或过弱
- 高速阻力上升不足，导致"白赚能量"

### 4.3 传感器/武器/终止逻辑也依赖平台动力学

空战不只是"看见就打"。平台动力学会改变：

- closure rate
- 姿态稳定性
- 发射前平台可控性
- 脱战/再攻击窗口
- 导弹发射包线的进入和退出节奏

因此，哪怕武器链路和终止规则都写对了，平台动力学一旦偏差过大，
上层结果仍然会失真。

## 五、当前主线里最会影响空战推进的飞行动力学风险

结合现有飞行动力学分析和 `1v1` 训练现状，当前最值得警惕的不是"模型还不够精细"本身，
而是以下失真已经开始直接影响空战训练表现。

### 5.1 跨/超声速压缩性缺失会扭曲能量管理

现有气动模型中：

- `Cl_alpha`
- `Cd0`
- `k`
- `Cm_alpha`

都没有可靠的马赫依赖修正。

这意味着：

- 高速可用升力可能被错估
- 波阻缺失会低估高速能量损失
- 高空高速和中低空亚声速的性能差异会被压平

对于空战，这不是"细节问题"，而是会直接改变：

- 追击是否值得
- 俯冲换速是否划算
- 保速盘旋和拉升脱离的收益顺序

### 5.2 当前裸机纵向静稳定特性仍像"经典稳定飞机"

当前 `Cm_alpha` 被硬编码成一架传统稳定布局飞机的数量级。

这会弱化现代战斗机最关键的一类行为差异：

- 放宽静稳定度
- 依赖 FBW 增稳后的机头指向能力
- 高攻角瞬态响应

因此，当前空战线如果继续推进到更强机动对抗，很容易把"现代战斗机空战"
训练成"传统稳定飞机 + 通用速率指令飞控"的策略。

### 5.3 发动机瞬态缺失会把"油门作弊"误学成战术

当前推力响应仍接近瞬时生效。

在空战里，这会带来两个直接后果：

- 策略会学到高频油门脉冲，而不是真实的能量管理节奏
- 速度恢复、拉升保持、拖滞再加速的时间常数都偏乐观

这类偏差不会只体现在"发动机看起来不真实"，而是会改写整套交战节奏。

### 5.4 高攻角恢复机制不足会把失速变成主要学习噪声

现有 `1v1` 烟测里已经出现非常具体的症状：

- `failfast_deep_stall` 主导终止
- 典型 `AoA` 能到 `50 deg+`
- `pitch` 能到 `77-82 deg`

这说明当前问题已经不是抽象的"也许会影响空战"，而是：
**飞行动力学/飞控/训练信号耦合已经在主线上真实暴露出了高攻角恢复与能量管理问题。**

## 六、继续展开空战模拟前的门槛与首批真实性测试

建议把飞行动力学验收分成三层。

### 6.1 Gate A：物理一致性

这层先回答"会不会明显违背基本物理"。

最低要求：

- 相同 `seed` 结果可重复
- 不出现非有限值
- 自由落体近似满足 `-g`
- 正负输入至少满足方向一致性和近似对称性

这层主要解决"代码是否坏掉"，不是"是否足够真实"。

### 6.2 Gate B：粗真实性守门

这层回答"趋势是否像飞机，而不是像某种被飞控硬拽着走的刚体玩具"。

至少应当自动化检查：

- 更大油门应带来更高的总比能变化
- 更大抬头输入应带来更高的迎角、更大的爬升和更明显的速度交换
- 左右滚转应近似镜像，且不应无端产生大侧滑
- 中低攻角区的基础响应应平滑、有限、可复现

这层不能证明"足够高保真"，但能阻止最危险的回归：
行为表面还像能飞，内部物理趋势已经反了。

### 6.3 Gate C：空战前置门槛

这层才回答"是否足以继续往更深的空战训练推进"。

优先建议的门槛是：

- 高攻角进入后存在可观测的恢复趋势，而不是只靠 failfast 末端处置
- 高速阻力与能量损失至少具备正确趋势
- 爬升/俯冲换速关系不出现明显反物理收益
- 发射前平台姿态与能量状态不会长期停留在非现实高攻角区

当前主线距离这层门槛仍有缺口，因此更适合把当前阶段表述为：

- 空战流程底座已具备
- 飞行动力学真实性守门正在补齐
- 暂不宣称"可信空战机动性能"

### 6.4 首批建议自动化的真实性守门项

本轮先落地一批粗真实性守门测试，目标不是给出机型级认证，而是提供
空战推进前的最低物理趋势检查。

#### 6.4.1 油门-总比能排序

目标：

- `idle` 与 `full throttle` 相比，后者应明显提高总比能
- 至少不能出现"推力更大但总比能更差"的反常趋势

意义：

- 它比单看 `IAS` 更接近空战所关心的能量状态
- 能较早暴露推力/阻力/重力耦合回归

#### 6.4.2 抬头输入的速度-高度交换

目标：

- 更大的抬头输入应带来更大的爬升收益
- 同时伴随更高的 `AoA` 和更明显的速度损失

意义：

- 检查纵向机动是否具备基本的能量守恒直觉
- 防止"抬头几乎白送高度"或"抬头不带来 AoA 增长"这类失真

#### 6.4.3 左右滚转镜像性

目标：

- 左滚与右滚在相同幅度输入下应表现为近似镜像
- 横向偏移方向相反且量级相近
- 不应无端引入过大的 `beta`

意义：

- 检查横侧向响应是否存在符号错误或非对称耦合异常
- 这类问题在空战中会直接污染 break turn / jink / out-of-plane 机动

#### 6.4.4 中低攻角区响应有界

目标：

- 在这些 probe 里，`AoA`、`G`、`roll`、`pitch` 都应保持在可解释范围内

意义：

- 不是要求"真实极限"，而是先把最危险的数值性漂移挡住

### 6.5 本轮已落地的首批测试

本轮新增：

- [tests/runtime/air_combat/test_flight_dynamics_realism_guards.py](../../../../tests/runtime/air_combat/test_flight_dynamics_realism_guards.py)

覆盖内容：

1. `full throttle` 相比 `idle` 的总比能排序
2. 不同抬头输入下的高度收益 / 迎角增长 / 速度交换趋势
3. 左右滚转镜像性与侧滑约束

运行方式：

```bash
source tools/maintenance/cmo_env.sh
cmo_env_validate
cmo_python -m pytest -q tests/runtime/air_combat/test_flight_dynamics_realism_guards.py
```

注意：

- 这些测试是 **coarse realism guards**，不是机型保真认证
- 它们的定位是"在继续扩展空战线前，先确保底层趋势没有明显跑反"

### 6.6 这些测试明确还不能证明什么

即使首批守门测试都通过，也不能据此宣称：

- 已具备可信的跨/超声速空战物理
- 已具备可信的过失速机动
- 已具备可信的现代战斗机 RSS / FBW 机动特性
- 已具备可信的发动机瞬态与能量恢复节奏

换句话说，它们只证明：

- 当前模型在若干关键输入-输出关系上仍保持"像飞机"的趋势
- 而不是已经达到了战术级高保真

### 6.7 建议的下一轮补强方向

若继续把飞行动力学作为空战前置线推进，建议下一轮优先补：

1. `pitch break / stall recovery` 守门测试
2. `Mach` 变化下的配平与阻力趋势测试
3. 发动机阶跃油门响应测试
4. 高速俯冲与拉起过程中的总比能一致性测试

其中：

- `Mach` 修正
- 发动机瞬态
- 失速恢复趋势

仍应视为当前最重要的三项物理前置工作。

## 七、合并后结论

在当前仓库里，更准确的推进口径应当是：

1. 飞行动力学已经足以支撑空战流程、武器链路和基础训练闭环。
2. 但它还不足以让我们放心地解释"学到的空战机动为什么正确"。
3. 因此，空战推进不能只看 reward、win rate 和武器链闭环；
   必须同时建立飞行动力学真实性守门。
4. 当前最重要的物理前置工作仍然是：压缩性修正、发动机瞬态、失速恢复趋势。
5. 本轮新增测试的价值，不是宣布"问题解决"，而是把这条守门线正式落到仓库中，
   让后续空战迭代至少不会在不知情的情况下继续放大底层动力学失真。
