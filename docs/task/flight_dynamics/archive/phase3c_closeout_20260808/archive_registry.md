# Flight Dynamics Archive Registry

Registration index for archived flight-dynamics subprojects under `docs/task/flight_dynamics/archive/`.

## Archived Subprojects

| Subproject | Description |
|-----------|-------------|
| `c2_command_chain/` | C2 command chain archive. Historical snapshots of command chain and communication analysis. |
| `flight/` | Flight dynamics archive. Historical documents on flight models, aerodynamics, and stability analysis. |
| `program/` | Expired Program subdirectory. Historical mainline status snapshot entrypoint, retained for traceability only. |
| `sensor_situation/` | Sensor and situational awareness archive. Historical snapshots of sensor model and situation assessment analysis. |
| `weapon_guidance/` | Weapon and guidance archive. Historical snapshots of weapon model and guidance law analysis. |
