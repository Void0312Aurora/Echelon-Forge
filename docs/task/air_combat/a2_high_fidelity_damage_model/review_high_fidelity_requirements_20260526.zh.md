# 空战高保真杀伤模型要求评审

状态：`2026-05-26` 独立评审。本文档从空战杀伤建模的领域要求出发，定义"高保真"的实质标准，而非从项目自身文档循环引用。

## 1. 问题陈述

当前 A2 子项目文档将"高保真"定义为自身声明的内容。Phase 1-3 和 Phase 5 被标记为"通过"，但对照实际空战杀伤建模的领域标准，这些 Phase 并未实现高保真——它们实现的是一个参数化的命中效果系统，带有子系统标记。

本文档的目的是：
- 从领域第一性原理定义空战杀伤模型的"高保真"意味着什么
- 为当前实现提供对照这些标准的独立基准
- 明确从当前状态到高保真的差距

## 2. 高保真杀伤链模型

高保真空战杀伤模型必须独立建模杀伤链的每一环。任何一环被启发式或黑盒替代，整个模型就退化为参数化游戏系统。

### 2.1 末端制导与 Miss Distance

**高保真要求**：Miss distance 必须由制导律、目标机动、导弹能量状态和导引头性能在闭环仿真中产生。

| 要素 | 当前状态 | 缺口 |
|------|---------|------|
| 制导律（PN/APN/最优制导） | 存在（PN 在 missile guidance 中） | — |
| 目标机动 → LOS 速率 → 导弹响应 | PN 闭环运行 | 末端规避到 miss distance 的耦合在制导模型中自然存在，但**未被损伤系统消费** |
| Miss distance 作为损伤输入 | `proximity_min_dist_m` 被跟踪 | 仅用于判定是否进入引信距离；不用于缩放损伤 |
| 末端规避对 miss distance 的影响 | 存在于制导回路 | **规避在损伤系统中被压缩为黑盒乘数**，而非通过 miss distance 传递 |

**模拟符合高保真要求需要**：miss distance 是制导末端博弈的结果，损伤模型通过接近程度（质量）消费 miss distance，规避效应通过 miss distance 传递而非单独的黑盒乘数。当前实现中 `evasion` 是独立乘数，与 miss distance 并存但无因果链路。

### 2.2 引信模型

**高保真要求**：引信模型必须区分引信类型、建模爆轰延迟/偏差、并产生目标几何中的 3D 爆轰点。

| 要素 | 当前状态 | 缺口 |
|------|---------|------|
| 引信类型（触发/雷达近炸/激光近炸/定时） | **不存在** | `fuse_distance` 是单一标量，不区分类型 |
| 引信延迟/偏差 | **不存在** | 爆轰发生在最近接近点，无延迟、无偏差 |
| 爆轰点相对目标几何 | `world_to_body()` 变换导弹位置 | 仅使用导弹位置（单点），不建模爆轰后膨胀的碎片云/冲击波 |
| 引信可靠性/失效概率 | **不存在** | 没有失效模式 |
| 引信触发条件（RCS/激光反射/触发阈值） | **不存在** | 仅基于距离阈值 |

**模拟符合高保真要求需要**：
- 引信类型决定触发条件和可靠性
- 雷达近炸引信：基于目标 RCS 和几何的触发概率
- 激光近炸引信：基于目标表面反射的触发距离
- 触发引信：需要物理接触
- 延迟爆轰（穿入后）建模延迟时间和穿入深度

### 2.3 战斗部效应

**高保真要求**：战斗部效应必须建模 3D 空间分布。不同战斗部类型有根本不同的杀伤机制。

#### 2.3.1 破片战斗部

| 要素 | 当前状态 | 缺口 |
|------|---------|------|
| 破片数量和质量分布 | **不存在** | 使用参数化衰减曲线替代 |
| 破片速度矢量（爆轰速度 + 导弹速度） | **不存在** | — |
| 破片空间分布（Mott 分布/指定模式） | **不存在** | 使用 `max_projected_hitboxes` 个最近 hitbox 替代 |
| 每个破片的命中/未命中 vs 目标暴露面积 | **不存在** | 没有暴露面积计算 |
| 破片穿透力 vs 装甲（THOR 方程或等效） | **不存在** | `armor` 字段从未被读取 |
| 破片对特定组件的条件杀伤概率 | **不存在** | — |

当前实现：选择最近 1-4 个 hitbox，应用 `severity × effect_scale × distance_attenuation`。这不是破片模型——这是距离衰减半径。

#### 2.3.2 连续杆战斗部

| 要素 | 当前状态 | 缺口 |
|------|---------|------|
| 杆膨胀环（半径、厚度、杆数） | **不存在** | 使用与破片相同的参数化曲线 |
| 杆-目标相交几何（环平面 vs 目标剖面） | **不存在** | `velocity_axis` 权重仅通过标量乘数近似 |
| 杆切割力学（动能/截面密度 vs 结构厚度） | **不存在** | — |

#### 2.3.3 爆轰战斗部

| 要素 | 当前状态 | 缺口 |
|------|---------|------|
| 峰值超压 vs 距离（Sachs 缩放或等效） | **不存在** | 使用衰减曲线 |
| 比冲量 vs 距离 | **不存在** | — |
| 目标表面反射/增强 | **不存在** | — |
| 结构失效阈值（超压、冲量、持续时间） | **不存在** | — |

**模拟符合高保真要求需要**：对于给定的战斗部类型和爆轰点（从引信模型导出），计算目标几何上每个暴露组件受到的损伤机制（破片命中模式 + 穿透力，或杆冲击，或超压/冲量），并判定每个组件是否失效。

### 2.4 目标脆弱性

**高保真要求**：目标脆弱性建模为组件级条件杀伤概率，对每个损伤机制类型具有特定阈值。

| 要素 | 当前状态 | 缺口 |
|------|---------|------|
| 组件级 hitbox | 4-6 个 OBB，覆盖大的区域（机头/机身/发动机/机翼） | 实际模型需要数十分项组件：飞控计算机、液压泵、发电机、燃油泵、发动机盘/叶片/燃烧室、雷达天线、座舱装甲等 |
| 每个组件的损伤机制特定阈值 | **不存在** | 所有组件使用相同的 `severity` 标量，基于系统名称进行相同的字符串分类 |
| 组件级失效概率（给定命中/破片/冲击波，组件失效的概率） | **不存在** | 累积损伤是确定性的 |
| 冗余建模 | **不存在** | Su-35 两个发动机被建模为独立 hitbox，但没有共享燃油/液压系统的逻辑；没有"单发失效→另一台发动机过度工作"的退化 |
| 方位角相关的暴露面积 | **不存在** | 3 个方位桶（nose/beam/tail）with 标量乘数，不是基于实际暴露组件面积的 3D 几何 |
| 特定组件的装甲 | **不存在** | `armor` 字段存在但从未在损伤代码中读取 |

**模拟符合高保真要求需要**：
- 每个组件对每种损伤机制具有特定的失效阈值
- 组件失效概率是命中特征（破片质量/速度/入射角、杆直径/速度、超压/冲量）的函数，而非通用标量
- 冗余系统正确建模——双发、双液压回路、双发电机
- 各向异性脆弱性通过 3D 几何计算——曝露面积随方位角和仰角变化

### 2.5 损伤传播与级联效应

**高保真要求**：损伤不仅限于直接命中的组件。级联效应传播损伤并通过功能依赖影响其他系统。

| 要素 | 当前状态 | 缺口 |
|------|---------|------|
| 火灾传播 | **不存在** | `fire_severity` 是一个标量，通过恒定速率独立衰减 |
| 液压级联 | **不存在** | 液压损伤被建模为飞控乘数限制，而非特定失效模式（卡滞、漂移、全自由） |
| 结构级联（翼梁损伤 → g-限制 → 如果超出则失效） | **部分存在** | `structural_overstress` 和 `flutter_exposure` 在高 g/马赫数下累积，但结构失效是渐进性乘数降低，而非灾难性失效事件 |
| 二次爆炸（燃油箱爆炸、弹药殉爆） | **不存在** | — |
| 电气/航电级联（发电机失效 → 总线切换 → 航电退化） | **不存在** | — |
| 飞行员损伤级联（受伤 → 任务能力降低 → 控制退化） | **部分存在** | `crew_effectiveness` 影响传感器和控制，但只是乘数 |

**模拟符合高保真要求需要**：
- 火灾有概率性起燃、速率取决于涉及的燃油/液压/电气数量、传播到相邻组件、以及抑制和烧穿的时间线
- 液压管路断裂导致特定致动器失效（例如，左升降舵冻结），而非针对所有控制面的通用乘数
- 结构失效是离散事件（翼梁在 g 负载下发生屈服），而非渐进性乘数
- 组件功能依赖图决定了损伤如何传播

### 2.6 杀伤评估

**高保真要求**：给定损伤状态，每个杀伤类别（机动杀伤、传感器杀伤、任务杀伤、K 级杀伤）的概率基于导致该杀伤类别的具体组件失效。

| 要素 | 当前状态 | 缺口 |
|------|---------|------|
| 从损伤状态推导杀伤类别 | 阈值规则（例如，`flight_control_kill = integrity < 0.25`） | 阈值是任意的（0.25、0.20），不是从失效数据中推导的 |
| 每个杀伤类别的概率 | **不存在** | 杀伤判定是确定性的 |
| 时间-关键杀伤（燃油耗尽时间、火灾烧穿时间） | **不存在** | 燃油泄漏存在但未集成到杀伤时间线中 |
| 杀伤类别之间的区别（部分 vs 完全） | 4 种类别（Mission/Mobility/Sensor/Lost） | 合理但粗粒度 |

## 3. 当前实现分类

对照上述标准，当前 A2 实现属于以下层次：

```
层级 0: 基于 HP 的杀伤（纯标量 damage → hp 扣除）
层级 1: 参数化命中效果 + 子系统标记     ← 当前 A2 Phase 1-3
层级 2: 组件级几何 + 损伤机制特定阈值
层级 3: 全物理杀伤链（制导 → 引信 → 战斗部 → 脆弱性 → 级联）
层级 4: 校准/验证过的杀伤链
```

当前实现位于**层级 1**。A2 文档称其为"高保真"，但这是错误的——它是参数化命中效果。高保真开始于层级 2，并在层级 3-4 达到。

### 达到层级 1 所需的具体工作（参数化命中效果 — 已完成）

- 命中点 → hitbox 选择（OBB 相交）：已存在
- 每个 hitbox 的受保护系统标记：已存在
- 每个飞机特定的 hitbox：已存在（4-6 个 OBB/飞机）
- 子系统损伤乘数向飞行包线的传播：已存在
- 弹头族乘数区分：已存在

### 达到层级 2 所需的具体工作（组件级几何 — 未开始）

- 将 hitbox 从 4-6 个区域细化到 ~20-50 个特定组件
- 用损伤机制特定阈值替换通用 `severity` 标量
- 读取并使用 `armor` 字段，匹配机制类型
- 计算方位角相关的暴露组件面积（3D 几何，而非 3 个方位桶）
- 添加组件级失效概率

### 达到层级 3 所需的具体工作（全物理 — 未开始）

- 末端制导 → 损伤耦合（规避通过 miss distance 传递）
- 引信类型建模（触发/雷达/激光/定时 + 延迟）
- 破片空间分布（Mott 或等效）+ 每个破片轨迹
- 穿透方程（THOR、FATEPEN 或等效）
- 级联效应（火灾传播、液压失效、结构失效事件）
- 冗余系统语义

### 达到层级 4 所需的具体工作（校准 — 未开始）

- 针对测试数据或验证过的物理模型进行组件失效阈值校准
- Pk 曲线验证
- 引信性能数据

## 4. 建议

1. A2 文档（README.md 和 cluster 文档）应修正当前"Phase 1-3+5 通过 = 高保真已实现"的隐含叙述。应明确声明当前模型处于**层级 1（参数化命中效果 + 子系统标记）**。

2. Phase 4（确定性引信）和 Phase 5（脆弱性证据）不应被视为"暂缓"或"scaffold"——它们代表了层级 2-3 所需的核心组件。如果目标确实是高保真，当前 deferral 策略意味着该项目距离高保真还有很长的路要走。

3. 应新增一个明确的 Phase 来覆盖：
   - 破片空间分布（无论是否简化——即使参数化 Mott 分布也会显著优于当前的最近-N-hitbox 方法）
   - 引信类型区分（至少区分触发/近炸）
   - 组件级失效概率（用概率性阈值替换确定性阈值）

4. 在基于测试数据或验证过的物理模型进行校准之前，不应声称"高保真"。纯粹的合成参数正如 `AircraftVulnerabilityProfile.synthetic=true` 所承认的那样——这本身就是目标未达成的标志。
