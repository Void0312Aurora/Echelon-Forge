# A2 组件脆弱性 benchmark 第三方 / 社区 / 开源来源 pin 更新

状态：`2026-05-28 third_party_community_pin_update / non-authoritative`。本文件补充 [source_ledger.zh.md](source_ledger.zh.md)，只记录可追溯第三方、社区、开源工具和开放数据集对 benchmark 方法设计的候选价值。所有条目默认 `authority=none`；不得进入 runtime descriptor、校准运行时行、Pk、fuze 或 component-failure authority。

## 准入边界

- 开源工具可以支持可复现 benchmark harness、geometry/shotline scaffold、fault-tree 求解器对照、uncertainty/provenance manifest；工具输出本身不是来源事实。
- 社区/开源配置只能作为 `open_source_config_candidate` 或 `community_sanity_check`；如配置来自游戏、商业仿真或未经审计的社区假设，不能用于 fragility/Pk。
- 开放数据集若缺 target/weapon/aspect/closure/miss-distance/mechanism-load/component exposure 轴，只能支持 benchmark shape、schema、data-quality tests 或 consequence taxonomy。

## Benchmark 方法映射

| benchmark design need | 候选来源 | 可做 | 仍禁止 |
|---|---|---|---|
| geometry-to-shotline toy harness | OpenVSP, TiGL, shotline papers from primary ledger | 生成 synthetic geometry、section/intersection/mesh fixtures，记录 commit、config、seed、checksum | 声称 F-16 internal component exposure 或真实 vulnerable area |
| fault-tree / dependency solver parity | SCRAM, OpenReliability FaultTree, MIT OCW/NRC/NASA FTA references | 用同一 synthetic dependency graph 比较 top-event logic、minimal cut sets、BDD/MOCUS output | 使用工具自带概率或 guessed probabilities 作为组件真值 |
| consequence simulation harness | JSBSim, NASA damaged-aircraft papers, FAA/NTSB accident cases | 构造 non-authoritative damaged-flight consequence tests，例如 thrust/control/hydraulic degradation | 声称 F-16C flight-control survivability 或 combat damage validation |
| open component damage observation dataset | Mendeley BVID/CFRP, J-DDL pending pointer | 设计 artifact manifest、label provenance、sensor/image/damage-state schema | 外推为 aircraft component kill threshold 或 AAM fragment effect |
| repairability / post-damage consequence taxonomy | RAND ABDR/ACE, NTIS/Air University ABDR, FAA/NTSB cases | 设计 `repairable`, `degraded`, `depot_required`, `cannibalized`, `lost_control` 等 non-authoritative taxonomy | 写真实 repair-time distribution、mission availability or battle-damage probability |

## 仍缺口

- `external_calibration_dataset` 仍为空；没有第三方/社区/开源资料满足 A2 runtime 所需的 target/weapon/aspect/closure/miss-distance/mechanism-load/component uncertainty 轴。
- `validated_physics_surrogate` 仍为空；上述工具只能帮助建立 harness，后续必须补 model card、source manifest、artifact hash、validation metrics、coverage 和 residual closeout。
- 开源 geometry/FDM/fault-tree 工具的版本、commit、dependency lockfile 和输出 checksum 还未固定；进入 artifact manifest 前必须补齐。
- 社区/开放 damage datasets 多为 surface/coupon/SHM，不覆盖内部组件、系统依赖和战斗损伤机制。
