## 仍缺或仍需复核

- PDF/file hash：NASA-STD-7009B Change 1、NASA-HDBK-7009B、FAA AC 25.1309-1B、FAA AC 20-128A、NASA NTRS PDFs 和 open-access PDFs 均未记录 sha256；不能作为 artifact manifest 的完整输入。
- `CFBM-MILHDBK-001`：仍缺 DLA ASSIST 当前 public distribution statement、document version/status、官方下载路径和 hash；未固定前只保留为 method/vocabulary candidate。
- `CFBM-BALL-001`：仍缺具体 edition/ISBN/page-scope pin；教材版权限制强，只可题录/自写摘要。
- `CFBM-PAPER-005` 与 SAGE/订阅类论文：公开 DOI/摘要可作为 pointer；全文 rights 不足时不得抽取数值或复用表图。
- 所有来源均缺 A2 runtime 所需的 target/weapon/aspect/closure/miss-distance/uncertainty 校准链；没有任何条目升级为 `external_calibration_dataset` 或 `validated_physics_surrogate`。
