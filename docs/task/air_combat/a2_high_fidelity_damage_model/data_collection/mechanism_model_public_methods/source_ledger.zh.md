# Source Ledger：公开机制模型方法

状态：`2026-05-28` 初版收集台账。所有记录默认 `non-authoritative`。本文件只记录公开方法来源和准入判断，不创建 vulnerability descriptor，不写真实校准 row，不授予 Pk、deterministic fuze、effect-scale 或 component-failure probability authority。

## 字段口径

| 字段 | 说明 |
|---|---|
| `source_ref` | 稳定 URL、DOI、报告号、标准号或题录入口。 |
| 发布方 | 出版社、标准/官方机构、公开工程资料发布方或来源持有人。 |
| 可公开性 / 权利 | 公开访问、版权/再分发限制、是否只能引用不能复制正文。 |
| scope 匹配 | 与 A2 空战 mechanism-load 的匹配程度，不等于具体型号匹配。 |
| 交叉验证状态 | 已有 Tier A/B 交叉、待交叉、只能 sanity check 或拒绝。 |
| 不确定性 | 采纳该来源后仍不能关闭的真实性缺口。 |
| A2 判定 | `mechanism_load_candidate`、`background_only`、`sanity_check_only` 或 `rejected_for_direct_calibration`。 |

| 载荷字段 | 推荐公开方法入口 | 当前使用等级 | 必须保留的 residual |

| `blast_overpressure_kpa` | Kingery-Bulmash hemispherical/spherical TNT burst via IATG + UFC source chain | `method_candidate` | 公式版本、单位、适用 Z 范围、空空近炸验证 |
| `blast_impulse_kpa_ms` | Kingery-Bulmash impulse equations and Sachs scaling | `method_candidate` | impulse 与 scaled distance 的适用域、反射 impulse、目标姿态 |
| `fragment_energy_j` | Gurney initial velocity + Mott mass distribution | `method_candidate_pending_original_report` | casing/charge mass ratio、材料、预制破片、方向图、速度衰减 |
| `fragment_areal_density_per_m2` | Mott/Gurney + spherical dilution / pattern proxy; IATG fragment hazard chapters as method navigator | `engineering_proxy_candidate` | 不能把安全距离碎片密度当命中概率；需要方向图和遮挡验证 |
| `penetration_margin` | Public ballistic-limit equation shape from NASA-HDBK-8719.14, Recht-Ipson DOI route, MIL-STD-662F ASSIST/QuickSearch lookup route, and DDESB TP-21 debris-analysis vocabulary; UFC 3-340-01 is rejected for use | `limited_method_candidate / validation_criteria_pending_artifact` | 超高速/航天材料域差异；V50 armor vocabulary不等于 aircraft component fragility；MIL-STD artifact/hash and conventional public penetration examples remain open |
| `rod_cut_margin` | JHU/APL continuous-rod historical mechanism description | `mechanism_shape_only` | 只支持切割/方向性概念，不能提供现代型号杆数、速度、半径或失效概率 |

## 不能直接转成校准参数的项目

| 项目 | 原因 | 允许用途 |
|---|---|---|
| Kingery-Bulmash 表/多项式直接写入 aircraft vulnerability row | blast 方法适用域是 TNT burst 工程载荷，不包含具体空空 missile warhead、目标局部反射和组件脆弱性 | 生成 `blast_*` mechanism-load proxy，再用公开验证或校准数据过滤 |
| Mott/Gurney 公式直接给 AIM-120C-class 破片数、质量、速度 | 缺少具体战斗部 casing、装药、预制破片和方向性公开数据 | 非型号化 fragment cloud surrogate 输入 |
| NASA orbital debris BLE 系数直接作为飞机穿透概率 | 速度域、材料、几何和失效模式不同 | 公开 BLE 结构和 validation checklist |
| Talos continuous-rod 历史尺寸或速度外推到现代导弹 | 历史特定型号且 scope 不匹配 | 背景和 `rod_cut_margin` 形状设计 |
| 论坛/民间数据库战斗部参数 | provenance、权利、版本和来源层级不满足准入规则 | 只做搜索线索或 sanity check |
