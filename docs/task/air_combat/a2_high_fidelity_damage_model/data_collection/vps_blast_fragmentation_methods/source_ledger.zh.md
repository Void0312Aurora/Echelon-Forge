# Source Ledger：VPS blast_fragmentation 公开方法来源

状态：`2026-05-28` 数据/方法来源收集台账。所有记录默认 `non-authoritative`。本文档只支持首个窄域 `validated_physics_surrogate` 候选包的方法和 benchmark 设计，不创建 runtime descriptor，不授予 Pk、deterministic fuze、effect-scale 或 component-failure probability authority。

候选 scope：`F-16C_Block50` x `AIM-120C-class/blast_fragmentation` x `beam` x `high` x `near_miss_0_35m`。

## 字段口径

| 字段 | 说明 |
|---|---|
| `source_ref` | 稳定 URL、DOI、报告号、标准号、ISBN、官方入口或待采集报告编号。 |
| 权利 | 公开访问、版权、再分发限制和仓库保留方式。默认只记录引用、摘要和可复现计划，不复制表格、长段正文或公式推导。 |
| Tier | 按 A2 来源准入规则的 `Tier A / Tier B / Tier C / rejected`；`pending` 表示 source_ref 或权利仍需固定。 |
| scope | 与本 VPS scope 的匹配程度。`method-only` 不等于型号级匹配。 |
| 可采纳内容 | 可进入未来 model card / validation report 的内容类型。 |
| 交叉验证 | 与其他 Tier A/B 来源的互证方式。 |
| 不确定性 | 采纳后仍未关闭的真实性缺口。 |
| admission/authority | 能否作为 `method_ref`、`benchmark_dataset`、`validation_criteria`、`reproducibility` 候选；是否可作为 authoritative descriptor row。 |
