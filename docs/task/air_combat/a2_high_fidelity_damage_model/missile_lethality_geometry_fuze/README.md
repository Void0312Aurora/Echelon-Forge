This path is retained only as the navigation entry for the completed second
phase. MLF-2 completed the observable chain for controlled approach geometry,
nearest-approach events, fuze-evaluation events, diagnostics projection, and
the runtime handoff gate.

Do not continue warhead effects, fragmentation, continuous rod, structural
breakup, debris/wreck objects, Pk, or AIM-120C/MQ-9 calibration inside this
archived MLF-2 subproject. The next phase must be created as a separate
`docs/agent` subproject.

Reusable conclusion: after a missile reaches the target area, the system can
now explain the nearest point, whether the fuze armed, whether it triggered,
why it did not trigger or failed, and whether detonation state was handed to
the later effects model. It still does not directly say the target fragments,
crashes, or is killed.
