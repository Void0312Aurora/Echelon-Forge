# A2 MLF-5 扩大方位/距离矩阵

状态：`2026-06-11` retained evidence。英文辅文：[missile_lethality_component_failure_expanded_matrix_20260611.md](missile_lethality_component_failure_expanded_matrix_20260611.md)。

本记录只说明部件级失效概率和抽样结果，不说明整机坠毁、结构解体、残骸、Pk 或真实弹种杀伤结论。

## 探测范围

- 弹头类型：`blast_fragmentation`、`continuous_rod`。
- 方位：右侧、左侧、鼻向、尾向、上方、下方、右侧上偏、右侧下偏。
- 距离点：每个主方位 4 到 6 个距离点；合计 `88` 个场景点。
- 每个点的随机抽样：`64` 个 reset seed。
- 统计口径：`model_p` 是主受影响部件的理论失效概率；`actual_fail_rate` 是至少一个部件抽样触发失效的比例。
- 直接命中点和普通近炸点已在热力图中用 `D` 分开标注。它们不应被当作同一条单调距离曲线。

## 保留边界

- 这些结果只说明部件是否抽样触发失效。
- 这些结果不说明目标一定坠毁，也不说明空中解体。
- 后续若要判断结构断裂、残骸或整机击落概率，应由后续阶段消费这些部件损伤事实。
