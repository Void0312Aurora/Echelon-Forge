# A1 1v1 真实度梯度

状态：`2026-05-25` 开启，用分阶段空战课程替换单一高难度 `1v1`
smoke 入口。

## 目的

当前 `F-16C_Block50 vs F-16C_Block50` 脚本红方 smoke 场景已经证明武器桥和
对抗终止钩子接通，但它不适合作为第一轮 RL 训练入口：

- HMoE 策略初始会把雷达和武器开关压在接近 0 的区域，早期 PPO 探索几乎到不了
  `master_arm` 加 `fire_weapon` 的组合；
- 红方初始就在 `9000 m` 开火窗内，可以从第 1 步开始发射；
- 即使强制蓝方持续开火，也不能稳定在红方命中蓝方前击毁红方。

本子项目定义四阶段课程：只有上一阶段的学习闭环可达、可测，才提升下一层真实度。

## 四个阶段

### 阶段 0：打击飞行中的红方无人机

目标：先让开火链路可达。

场景形态：

- 蓝方 F-16C 空中起始，并具备开火授权；
- 红方目标是正在飞行、无武器、无规避的无人机替身；
- 初始距离为近距到中距，约 `8-15 km`；
- 成功标准是策略能探索到雷达/武器开关、发射导弹，并获得 `combat_win`。

真实度范围：

- 保留真实 runtime 武器发射、弹药消耗、导弹飞行、毁伤和目标失活终止；
- 暂不要求目标规避、红方武器和 BVR 战术决策。

### 阶段 1：非机动目标上的距离扩展

目标：把同一开火链路扩展到第一层超视距距离。

场景形态：

- 红方目标仍然无武器、无规避；
- 初始距离扩展到约 `20-40 km`；
- episode 长度足够覆盖接触保持、导弹飞行时间和终端毁伤。

真实度范围：

- 发射距离、目标接触保持和导弹飞行时间开始变重要；
- 目标防御和双向威胁仍然延后。

### 阶段 2：会规避但武器锁定的战斗机

目标：引入机动战术，但不引入红方导弹压力。

场景形态：

- 红方换成脚本控制的战斗机；
- 红方可以 offset、beam、加速和保持高度；
- 红方没有可用导弹；
- 初始距离约 `40-70 km`。

真实度范围：

- 蓝方需要保持几何、选择更好的发射时机，并应对运动目标；
- 红方仍不能发射武器，因此失败可归因于追击、发射时机、传感器/接触处理或飞控。

### 阶段 3：部分解锁武器的战斗机

目标：在完整对等 `1v1` 之前，引入受控的双向威胁。

场景形态：

- 红方是有武器战斗机，但弹药和开火窗口受限；
- 初始距离在当前传感器模型允许范围内扩展到约 `70-120 km`；
- 第一版应使用延迟或距离门控的红方开火，避免 episode 起始即全向齐射。

真实度范围：

- 开始训练攻防权衡；
- 只引入有限双向武器，不进入完整 self-play 或多机战术。

## 进入下一阶段的门槛

每一阶段进入下一阶段前，应满足：

- 诊断中能观察到蓝方武器开关：雷达、总保险、发射指令和武器选择；
- 至少一个固定种子策略或脚本基线能产生正向 `combat_win` 样本；
- 终端奖励仍保持互斥：`combat_win`、`combat_loss`、`combat_draw` 不叠加无关
  crash 或 objective 奖励；
- 训练探针不产生 non-finite 报告；
- HMoE 路由和动作诊断足够解释失败 rollout。

## 可视化约定

本项目内提到空战 `viz` 时，默认指 `examples/viz` 交互式可视化入口，而不是
TensorBoard 或一次性诊断图。阶段 0 的首个可视化 profile 是：

`examples/viz/profiles/air_combat_1v1_stage0_forced_fire_debug.json`

用途：

- 观察定时开火动作下的目标接触、弹药下降、导弹飞行、目标毁伤和
  `combat_win` 终止；
- 对齐过程现象，不作为 RL 策略学习效果验收；
- 该 profile 使用单一 `fixed_action` 固定开火；观察交战细节时应使用
  `examples/viz` 的 `0.1x` 或 `0.05x` 慢放倍率，而不是引入多脉冲动作脚本；
- 若要观察训练策略，应通过 `--model` 加载 checkpoint，并避免使用固定动作
  profile。

  对长距离交战的边界。
