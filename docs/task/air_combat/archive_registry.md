# Air Combat Archive Registry

Registration index for archived air-combat subprojects under `docs/task/air_combat/archive/`.

## Archived Subprojects

| Subproject | Description |
|-----------|-------------|
| `a2_high_fidelity_damage_model/` | High-fidelity air combat damage model. Research/candidate profile for structured-aircraft damage/effects with blast-fragmentation evidence packets and G1-G5 research packets. Non-authoritative acceptance; stock authority, Pk, and deterministic fuze not released. |
| `a3_c2_roe_release_discipline/` | C2/ROE release discipline layer. Weapon control state, target identity, fire authorization, single-shot-then-assess / salvo / reattack permission, and mission observation constraints. Accepted. |
| `a4_authorized_first_shot_training_signal/` | Authorized first-shot training signal. Closed historical firing-learning line. Reward shaping, routing, diagnostics, and opportunity penalty did not solve firing. |
| `a5_constrained_event_action_model/` | Constrained event-action model. Closed. Contributed constrained hold/fire_once surface and the weapon-arm action-frame fix used by M3-S2. |
| `a6_event_value_first_event_timing/` | Event value and first-event timing. Closed. Hazard/deadline/window labels exposed useful timing evidence but did not become current firing authority. |
| `a7_event_value_advantage_credit_head/` | Event-Value / Advantage Credit Head. Closed. Event-credit work belongs to timing-quality research history; current launch closure belongs to M3-S2. |
| `a8_damage_effect_chain/` | Damage effect chain. Accepted bounded slice. Missile effects → specific aircraft component damage → propulsion/fuel/sensor/fire/flight consumption path propagation. No direct crash or target-specific kill rules. |
