A8 is accepted for the bounded damage-effect-chain slice: public shot rows,
concrete synthetic failure modes, and fixed MQ-9/AIM-120C-like cases explain the
path from detonation to damaged part and maintained-system response. Covered
responses include propulsion, wing/control aerodynamics, fuel/leak/mass,
broader fire, data-link mission/sensor degradation, and original-entity
ground-contact lifecycle observability.

This acceptance does not add a direct crash rule, special MQ-9 kill rule, real
Pk claim, deterministic fuze claim, stock AIM-120C lethality claim, or
first-class debris/residue objects. Reopen those topics only through explicit
calibration, authority, platform-expansion, or residue-object work.
