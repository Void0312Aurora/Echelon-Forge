# A7 Projection Eligibility Root-Cause Audit

Status: `2026-06-04` `A7-EVC-O Projection Eligibility Root-Cause Audit` pass.
The projected legal-open path is implemented and can activate when
`shadow_quality` rows exist, but the N learned run starves that branch because
its training rollouts do not contain accepted early releases and therefore do

## Question

`A7-EVC-N` showed:

- projection is enabled: `a7/evc_proj_enabled=1.0`;
- ordinary A7 event-credit is live:
  `a7/event_credit_active_count_mean=450.0` at step `32768`;
- projected active rows remain `0.0`;
- projected unsupported rows also remain `0.0`.

The audit question is therefore narrower than "projection failed": is there no
shadow candidate, is the candidate rejected by projection eligibility, or is
the train/probe handoff dropping fields?

## Code Path Finding

Current `AdaptiveKLPPO._first_event_credit_loss()` activates projection only
for active rows whose first-event source is `A6_FIRST_EVENT_SOURCE_SHADOW_QUALITY`.
Those rows are generated by `build_first_event_hazard_labels()` only after an
early accepted first release closes the ordinary fire mask and later
launch-window quality evidence appears.

So M projection is a post-early-release repair path. It is not a general
quality-window opportunity-credit path.

## Root Cause

The M projection path is behavior-contingent on the failure mode it tries to
repair. It supplies legal-open projected positives only after the policy samples
an early accepted release. When the rollout contains no accepted release, A7
falls back to ordinary deadline/prewindow labels, and the projection branch is a
no-op.

This explains the N split:

- deterministic/probe no-release trajectories expose deadline positives but no
  projection candidates;
- stochastic/probe early-release trajectories expose many shadow candidates;
- training diagnostics from N show no accepted release in the logged rollouts,
  so projected active rows remain zero.

## Ruled Out

- Unsupported observation layout: not primary. N has
  `a7/evc_proj_unsupported_count_mean=0.0`.
- Projection implementation path: not primary. Focused M tests activate
  projected rows and update event logits.
- Launch-window gate disabled: not primary. The active config has
  `a6_first_event_launch_window_enabled=true`, and probe reconstruction creates
  deadline/shadow labels from the same launch-window settings.
- Missing ordinary A7 labels: not primary. Ordinary event-credit active counts
  and positive fractions are live.

## Next Direction

`A7-EVC-P Legal-Open Opportunity Credit Contract` should define a credit source
that is not conditional on an early accepted release. The likely contract is:

- keep `shadow_quality` projection as a repair path for early-release
  trajectories;
- add a legal-open opportunity source for no-release quality-window rows, so
  projection/value-to-policy coupling can receive positive legal-open evidence
  before the policy already samples the failure mode;
- keep A3/A5 masks authoritative and do not align raw closed-mask rows directly
  to event logits.
