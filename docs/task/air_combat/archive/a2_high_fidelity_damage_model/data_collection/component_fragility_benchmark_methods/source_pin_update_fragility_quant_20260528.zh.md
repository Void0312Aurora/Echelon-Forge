# A2 组件脆弱性量化 benchmark 来源 pin 更新

状态：`2026-05-28 fragility quant gap update`。本文补充公开、合法、可引用的组件脆弱性量化 / 故障后果 / 冗余依赖 benchmark 候选。所有条目只用于文档态来源收集、方法设计、benchmark 设计或 sanity check；不创建运行时 descriptor，不写校准运行时行。

## 准入边界

- 只记录官方公开页面、NASA/FAA/NTSB/DoD 页面、大学或 Zenodo DOI 记录、开放期刊 DOI 记录。
- 只使用这些 source role：`method_reference`、`validation_criteria_reference`、`benchmark_design_reference`、`sanity_check_only`、`pending_acquisition`、`rejected_for_use`。
- NASA Open Data 的 `source_hash` 只视为门户元数据 hash；除非另行下载并记录文件 checksum，否则不等同于可复现 artifact hash。
- 民航维护、健康管理、事故/事件、安全报告和实验室故障注入数据不能外推为 AAM/F-16 战斗损伤组件概率。

## 当前可用结论

| gap item | 可用公开来源 | 当前最高用途 |
|---|---|---|
| 组件/子系统依赖传播 benchmark | NASA ADAPT, FAA JASC, FAA SDR, ASRS maintenance reports | `benchmark_design_reference` / `sanity_check_only` |
| 发动机、电源与作动器健康退化 time-series benchmark | NASA C-MAPSS Jet Engine Simulated Data, NASA N-CMAPSS, NASA ADAPT, NASA EMA diagnostic/prognostic record | `benchmark_design_reference` |
| 材料/结构损伤和 uncertainty 方法 | NASA CFRP records, MDPI 2025 aircraft panel fragment paper, existing AEJ/FOI/open vulnerability papers | `method_reference` / `benchmark_design_reference` |
| 民航事故/维护后果 taxonomy | FAA SDR/JASC, NTSB CAROL, ASRS | `sanity_check_only` / `validation_criteria_reference` |
| DoD severity / risk vocabulary | MIL-STD-882E Change 1 official `.mil` copy | `validation_criteria_reference` |

## 剩余缺口

- 仍未找到公开、可再分发、scope 匹配并含 uncertainty 的 air-combat aircraft component fragility calibration dataset。
- 仍缺 F-16 级公开内部组件布局、冗余、线束/液压/电源依赖与战斗损伤试验数据。
- NASA/FAA/NTSB/NGAFID 数据多可支撑 benchmark design，但缺 target/weapon/aspect/closure/miss-distance 和 hit/load mechanism 轴。
- 多数官方数据页面缺资源文件 checksum；进入长期 artifact manifest 前必须下载、固定版本、记录 sha256、保留 retrieval date 和许可。
- 开放论文可引用方法和公开图文，但当 data availability 声明不公开底层数据时，不能把图表读数转成项目数据行。
