Status: `2026-06-02` archived pointer. The full evidence package was moved to

bridge through normalized `TaskOrder -> LeaderIntent -> PilotReport`, without
claiming command delivery, observation/export, movement, sensing, terrain,
fires, damage, combat, or broad facade authority.
