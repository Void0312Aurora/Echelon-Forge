# 当前引擎能力说明 (v0.0.1)

你现在拥有的是一个**最小可行性产品 (MVP)** 级别的仿真内核。为了让你更直观地理解，我们可以用“即时战略游戏 (RTS)”或“桌面兵棋”来类比。

## 1. 核心能力：它现在能做什么？

目前引擎就像一个**“绝对听话、绝对精准的棋盘”**。

### A. 它是“活”的 (Simulation Loop)
*   **能力**：引擎可以按固定的时间步长（比如每秒 60 次）推进世界。
*   **意义**：这保证了时间流逝是均匀的。不同于现实世界“一旦过去就回不来”，这个引擎里的时间是严丝合缝的，很适合让 AI 学习“因果关系”。

### B. 它能管“棋子” (Entities & Components)
*   **能力**：你可以创建任意数量的单位（飞机、舰船、导弹）。
*   **当前属性**：
    *   **位置 (Transform)**：它在空间中的 X, Y, Z 坐标。
    *   **阵营 (Alliance)**：它是红方还是蓝方。
    *   **速度 (Velocity)**：它当前往哪个方向飞，飞多快。

### C. 它懂“运动” (Movement System)
*   **能力**：当你设置了速度，引擎会自动在每一帧更新位置。
*   **限制**：现在的运动是“瞬时的”。你让它停，它马上停（没有惯性）；你让它转弯，它马上转（没有转弯半径）。把它想象成**UFO 或者这里是太空**，没有空气阻力。

### D. 它是“确定”的 (Determinism)
*   **能力**：如果你重置，给相同的随机种子，不管跑多少次，第 1000 帧的所有单位位置都分毫不差。
*   **意义**：这是训练 AI 的**黄金标准**。AI 需要明确知道“我这次输了是因为我策略不对”，而不是“因为引擎这次骰子掷得不一样”。

---

## 2. 也是最重要的：它现在“不能”做什么？

了解局限性对制定下一步计划至关重要。

*   **没有“感知” (Blindness)**：
    *   目前的单位是**全盲**的。红方不知道蓝方在哪，除非我们在 Python 层“作弊”直接告诉它。
    *   *下一步计划*：我们需要写一个“传感器系统 (Sensor System)”，算视线 (Line of Sight) 和雷达范围。

*   **没有“交互” (No Combat)**：
    *   两架飞机撞在一起会穿过去（没有碰撞体积）。
    *   没有武器，不能开火。
    *   *下一步计划*：需要“判定系统”，比如距离小于 X 且处于敌对阵营 -> 触发“击毁”事件。

*   **没有“大脑” (No AI)**：
    *   单位不会自动追击敌人，不会自动避障。它只会傻傻地按你最后给的速度直线飞，直到飞出地图边界。
    *   *这正是我们要训练 AI 做的事*。

## 3. 演示案例：简单的“拦截”逻辑

为了展示虽然引擎很简单，但已经能玩起来，我为你写了一个 `examples/intercept_demo.py`。

在这个演示中，我们不通过引擎底层实现“自动追踪”，而是**在 Python 层模拟一个简单的 AI 能够做到的事**：
1.  获取自己和敌人的位置。
2.  计算方向向量。
3.  调整自己的速度去撞向敌人。

这正是未来 AI Agent 要做的事情：**观察 (Observation) -> 决策 (Action) -> 引擎执行 (Execution)**。
