# `archive/`

This directory stores closed, experimental, or trace-only historical plan
documents.

The archive preserves the original topical structure:

- [architecture/](architecture/README.md): archived `src/` layering records.
- [runtime_facade/](runtime_facade/README.md): archived runtime facade launch
  and cleanup records.
- [exact_runtime/](exact_runtime/README.md): archived exact-runtime and GPU
  route records.

Usage rules:

- These documents are not current implementation authority.
- The topical subtree structure should stay stable for traceability.
- The archive should be used only for historical judgment and stable
  cross-references.
