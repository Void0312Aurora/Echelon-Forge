# Log Notes

This directory is reserved for retained log summaries that need to stay in the
documentation tree. It should not be used for raw runtime logs, checkpoints, or
large generated outputs.

When a log note is retained here, include:

- the date and producing command or workflow
- the related task, plan, or test run
- whether the note is current evidence or historical provenance
- links to any durable artifacts outside this directory

Empty or scratch records should stay out of this folder until they have a clear
retention purpose.
