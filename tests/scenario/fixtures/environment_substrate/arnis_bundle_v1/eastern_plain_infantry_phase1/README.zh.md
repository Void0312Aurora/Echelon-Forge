# Eastern Plain Infantry Phase 1

这是一个供陆战单兵训练管线使用的**虚构农业平原样本**。它不是现实战场的
坐标，也不用于复原或推断现实行动。bbox 选择了美国中部的平坦高程覆盖区，
只作为“东欧农业平原形态”的非冲突地貌类比；OSM 几何本身仍是合成的，不代表
该位置的真实道路或聚落。

## 几何组成

- 约 1.7 km × 1.3 km 的 WGS84 bbox，作为单兵训练的第一张战术瓦片；
- 大片 `landuse=farmland` 农田；
- 三条狭长 `natural=wood` 树带/防护林；
- 东西两处小型聚落和少量建筑；
- 一条南北向河流、一个桥面和若干农道；
- 所有几何均为本仓库冻结的合成 OSM 风格输入。

## Arnis phase-1 作用

`request.json` 可以交给固定的 `arnis-cmo` 生成连续米制 bundle；本样本使用
USGS 3DEP 高程和 ESA WorldCover 地表覆盖。当前适配器会
保留 DEM、分类地表覆盖、道路、建筑和水系；它不会把树带、农田、多边形聚落
自动发布为通行性、遮蔽、视线或火力 runtime。

因此这份样本的验收分两层：

1. `expected/`（生成后才可填写）验证 Arnis bundle 的来源、校验和和静态几何；
2. `field_acceptance.json` 检查坡度分位数、开放地表覆盖比例、树覆盖比例和
   关键语义数量；
3. 单兵训练侧另外保存树带、农田和聚落语义叠加层，并在 runtime 真正消费前保持
   metadata-only / held。

即使 `expected/` 通过校验，也不得把本目录描述成已经完成的单兵可行走地图；
它仍是静态环境证据，通行性、路线和观察 runtime 还没有发布。
