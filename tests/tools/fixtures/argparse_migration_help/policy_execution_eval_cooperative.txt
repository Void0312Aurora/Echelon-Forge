usage: policy_execution_eval.py [-h] [--mode {cooperative,single}] --scenario
                                SCENARIO --train_config TRAIN_CONFIG --model
                                MODEL [--algo ALGO] [--episodes EPISODES]
                                [--seed SEED] [--stochastic] [--device DEVICE]
                                [--include_visual | --no-include_visual]
                                [--include_proprio | --no-include_proprio]
                                [--mission_obs_mode {basic,nav_v1,nav_v2,nav_v2_formation_v1,nav_v2_formation_role_v1,nav_v2_cooperative_takeoff_v1,naval_screen_station_v1}]
                                [--visual_downsample VISUAL_DOWNSAMPLE]
                                [--visual_update_interval VISUAL_UPDATE_INTERVAL]
                                [--temporal_history_len TEMPORAL_HISTORY_LEN]
                                [--action_mode {full,takeoff2,takeoff4,naval_station3,air_combat_hybrid_v1}]
                                [--execution_step_runtime_mode {compiled}]
                                [--step_info_mode {full,terminal,off}]
                                [--flight_shaping_backend {auto,compiled,gpu_host}]
                                [--json_out JSON_OUT]
                                [--max_world_steps MAX_WORLD_STEPS]
                                [--n_worlds N_WORLDS]
                                [--curriculum_stage CURRICULUM_STAGE]

Evaluate single-agent and cooperative learned execution policies.

options:
  -h, --help            show this help message and exit
  --mode {cooperative,single}
                        Evaluation mode.
  --scenario SCENARIO
  --train_config TRAIN_CONFIG
  --model MODEL         Path to SB3 model zip.
  --algo ALGO           auto / AdaptiveKLPPO / PPO
  --episodes EPISODES   Number of world episodes to evaluate.
  --seed SEED           Starting seed. Each episode increments by 1.
  --stochastic
  --device DEVICE       Policy inference device: auto / cpu / cuda
  --include_visual, --no-include_visual
                        Override env visual flag from train config.
  --include_proprio, --no-include_proprio
                        Override env proprio flag from train config.
  --mission_obs_mode {basic,nav_v1,nav_v2,nav_v2_formation_v1,nav_v2_formation_role_v1,nav_v2_cooperative_takeoff_v1,naval_screen_station_v1}
  --visual_downsample VISUAL_DOWNSAMPLE
  --visual_update_interval VISUAL_UPDATE_INTERVAL
  --temporal_history_len TEMPORAL_HISTORY_LEN
  --action_mode {full,takeoff2,takeoff4,naval_station3,air_combat_hybrid_v1}
  --execution_step_runtime_mode {compiled}
  --step_info_mode {full,terminal,off}
  --flight_shaping_backend {auto,compiled,gpu_host}
  --json_out JSON_OUT   Optional JSON output path.
  --max_world_steps MAX_WORLD_STEPS
  --n_worlds N_WORLDS   Evaluation world count. Recommended to keep at 1.
  --curriculum_stage CURRICULUM_STAGE
                        Curriculum stage index to apply before reset. Default:
                        last configured stage.
