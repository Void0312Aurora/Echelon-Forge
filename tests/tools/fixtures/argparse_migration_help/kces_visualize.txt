usage: kill_chain_expectation_visualize.py [-h] --input INPUT
                                           [--output-dir OUTPUT_DIR]
                                           [--prefix PREFIX]
                                           [--variant VARIANT]
                                           [--target-motion-layer TARGET_MOTION_LAYER]
                                           [--date-stamp DATE_STAMP]

Render KCES before-report heatmap rows to CSV, PNG, and SVG matrices.

options:
  -h, --help            show this help message and exit
  --input INPUT         Before-report JSON path.
  --output-dir OUTPUT_DIR
                        Output directory. Defaults to the input file
                        directory.
  --prefix PREFIX
  --variant VARIANT
  --target-motion-layer TARGET_MOTION_LAYER
  --date-stamp DATE_STAMP
                        Filename date stamp, for example 20260623. Defaults to
                        today.
