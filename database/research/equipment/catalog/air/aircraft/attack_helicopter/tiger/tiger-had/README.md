## Configuration Boundary

The French retrofit release establishes the operator and HAD upgrade context. The Airbus brochure supplies the variant-level geometry, engine, mass, fuel and conditioned performance block; the missions page supplies weapon capacities. HAP, UHT and Tiger MkIII values are excluded. Weapon rows list qualified/compatible options, not a simultaneous loadout.
