## Identity

- Family: NH90
- Variant: NFH (NATO Frigate Helicopter)
- Role: Naval multi-role helicopter
- Manufacturer: NHIndustries, a consortium of Airbus Helicopters (62.5 percent), Leonardo (32 percent) and Fokker (5.5 percent)
- Configuration scope: the manufacturer separates the NFH from the TTH on maximum gross weight. Common figures are recorded as platform-level.

## Configuration Boundary

The NFH and TTH maximum gross weights differ by 400 kg and are recorded separately rather than merged. The three dimensions and the useful-load row carry a lower confidence than the performance rows because the captured manufacturer section did not include the external-dimensions table; those values come from a transcription of the same programme's technical data and are marked accordingly. The manufacturer page marks several performance figures with a footnote whose reference condition could not be captured, so those rows carry the manufacturer value without an asserted condition.

Empty weight, powerplant and weapon-load figures are not recorded because no held source states them for the NFH.

The French Ministry of the Armed Forces page held for this leaf returns a site-under-maintenance response as of 2026-09-18. The manufacturer page is the authoritative source actually reachable.
