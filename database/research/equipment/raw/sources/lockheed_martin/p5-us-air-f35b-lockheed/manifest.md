## Extracted parameter notes

The sheet's variant table returns: length 51.4 ft / 15.7 m for the A, 51.2 ft / 15.6 m for the B and 51.5 ft / 15.7 m for the C; height 14.4 ft / 4.38 m, 14.3 ft / 4.36 m and 14.7 ft / 4.48 m; wingspan 35 ft / 10.7 m, 35 ft / 10.7 m and 43 ft / 13.1 m; wing area 460 ft² / 42.7 m², 460 ft² / 42.7 m² and 668 ft² / 62.1 m²; horizontal tail span 22.5 ft / 6.86 m, 21.8 ft / 6.65 m and 26.3 ft / 8.02 m.

The maximum weight row is the one row this package is admitted for, and it is carried on the leaf for the B mark: 60,000 lb class. The same row gives 70,000 lb class for the F-35A and 70,000 lb class for the F-35C; neither is carried on the F-35B leaf.

## A note on the class figures

The sheet publishes the maximum weights as class figures rather than as exact limits, and the word `class` is part of the value. The B leaf records `60,000 lb class` and does not convert it to a precise metric equivalent, because doing so would assert a precision the source does not state. An official United States Marine Corps page held as `p5-us-air-f35b-1stmaw` states the same 60,000 lb class figure with a 27,216 kg conversion of its own, which is recorded there rather than here.

## Why this package exists

The F-35B leaf previously carried a maximum take-off weight of 60,000 lb, converted to 27,200 kg, from a Tier C compilation that named no single artifact for the figure. The prime contractor's own document states the value and labels it a class, which is the reading the leaf now carries; the Tier C reading is retained as a recorded alternative on `p5-uk-air-f35b-migflug` rather than deleted.
