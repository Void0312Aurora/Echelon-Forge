## Responsibility

Stores retained raw source material or source-package manifests for the global equipment research program. P5 countries are the first mandatory baseline; additional countries are added through operators and country indexes, not duplicated raw subtrees.

## Hierarchy

- Parent: `../`
- Children: `sources/`

## Source Package Rule

Store each retained source under `sources/<publisher>/<source_id>/`. Every package must contain a manifest and a retention note. Tier, country, domain, equipment applicability, access date, and source type are metadata. When a source is secondary or community-maintained, the manifest must identify the author/maintainer where available and state that the values are not official specifications. One source package may support many equipment records and many operators.
