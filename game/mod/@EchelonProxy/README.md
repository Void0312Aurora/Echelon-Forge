# Echelon Proxy Mod

Local-only Arma mod shell for authoritative-backend experiments.

This mod is intended to:

- load the `echelon_bridge` extension from the mod root;
- install a lightweight SQF pump;
- keep an Arma aircraft as a proxy presentation shell;
- pull authoritative aircraft state from the external backend path.

The first draft targets single-player local testing only.
